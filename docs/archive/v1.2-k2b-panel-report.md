Result node/request matching and idempotence run in the acceptance transaction. Disconnect and reconnect convert outstanding pending rows to unconfirmed, without retrying. Empty settings mean clear. ## API JSON

`GET /api/v1/nodes/{id}/metrics?hours=1..168` (Owner/Viewer; default 24 hours):

```json
{
  "intervalSeconds": 60,
  "sampleSeconds": 60,
  "points": [{
    "at": "2026-10-29T12:00:00.000000000Z",
    "cpuPercent": 0,
    "memoryPercent": null,
    "diskPercent": null,
    "memoryUsedBytes": 123,
    "swapUsedBytes": null,
    "diskUsedBytes": null,
    "load1": null,
    "processCount": 0,
    "tcpConnections": null,
    "udpSockets": null,
    "activeConnections": null,
    "rxBytesPerSecond": 15,
    "txBytesPerSecond": null,
    "samples": 1
  }]
}
```

Up to 12 hours returns raw minute points. Longer ranges use epoch-aligned ceil(hours*60/720)*60-second buckets. Every measured value, including CPU, is the arithmetic average of non-null values; no additional CPU max field is emitted. Samples counts rows, including rows missing particular measurements. Counts/bytes can become fractional averages. Empty points is `[]`. Deleted nodes return 404.

`GET /api/v1/nodes/{id}/tuning` (Owner/Viewer):

```json
{
  "supported": true,
  "desired": {"net.core.somaxconn": "128"},
  "requestId": "unique-request-id",
  "status": "applied",
  "result": {
    "requestId": "unique-request-id",
    "status": "applied",
    "keys": [{"key": "net.core.somaxconn", "value": "128", "applied": true}]
  },
  "requestedAt": "2026-10-29T12:00:00.000000000Z",
  "updatedAt": "2026-10-29T12:00:01.000000000Z",
  "current": {"net.core.somaxconn": "128"}
}
```

Result uses protobuf JSON (default scalar values may be omitted). With no saved operation: desired/current are empty objects as applicable; requestId/result/requestedAt/updatedAt are null; status is unconfirmed. Current values come from the last heartbeat and may be stale; node lastHeartbeat/status are available separately.

`PUT /api/v1/nodes/{id}/tuning` (Owner + CSRF):

```json
{"settings":{"net.core.somaxconn":"128"},"clear":false,"confirmNodeId":"node-id"}
```

Clear request:

```json
{"settings":{},"clear":true,"confirmNodeId":"node-id"}
```

HTTP 202:

```json
{"requestId":"unique-request-id","status":"pending"}
```

Settings replace the whole profile. Unknown JSON fields are rejected by httpapi.Decode. Busy/unsupported/offline outcomes are HTTP 409. Invalid profile or confirmation is HTTP 400. Deleted nodes return 404.
