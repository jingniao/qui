# Walkthrough fix E — desktop-width (1120 px) squeezing and logic bugs

Date: 2026-10-29. Uncommitted changes only.

Scope: the browser walkthrough ran at a 1120 px viewport with a ~270 px sidebar,
so the content column is ~785 px while the layouts switch at Tailwind `lg`
(1024 px) and `xl` (1280 px). Everything below fixes squeezing, truncation and
overflow at that width plus the listed logic bugs. Layouts and visual style at
≥ 1440 px are unchanged except where the item explicitly asked for new column
counts. `web/src/modules/proxy/pages/RelayCanvasPage.vue`,
`web/src/modules/proxy/pages/ProxyNodeListPage.vue`,
`web/src/modules/proxy/api.ts` and `internal/` were not touched (another agent
owns them).

## 1. Tables — the last column is pinned

- `web/src/components/DataTable.vue`
  - `th:last-child` / `td:last-child` are `position: sticky; right: 0; z-index: 1`
    inside the existing `overflow-x-auto` viewport, so 操作 (编辑/删除) and 结果
    stay reachable without scrolling. The rules are declared after the existing
    `:deep(th)` / `:deep(td)` blocks and only add new properties, so the shared
    padding, `white-space: nowrap` and row transition keep working.
  - Opaque surfaces: header `#F5F5F7` (same as the `thead`), body `#FFFFFF`
    (same as `panel-card`), hover `#F9F9F9` (the opaque equivalent of the 2.5 %
    black row tint over white, so nothing shows through).
  - The left shadow (`-6px 0 8px -6px rgba(0,0,0,.18)`) only appears while the
    container is actually scrolled: the viewport element is referenced, a passive
    `scroll` listener plus a `ResizeObserver` toggle `dt-sticky-shadow`, and both
    are released on unmount.
  - Trade-off, documented deliberately: rows with their own translucent tint (the
    purple admin rows on `/users`) show the neutral row colour under the pinned
    cell rather than the tint. A translucent pinned cell is not an option — the
    content would bleed through it.
- Pages with their own `<table>` (`ServerTuning.vue`, `NodeEditorDrawer.vue`,
  `BackupSchedulePanel.vue`, `RestorePreviewPanel.vue`,
  `StorageObservationPanel.vue`, the two tables in `UserDetailPage.vue`) were
  audited: none of them ends in an actions column (草稿 editor, 登记大小,
  备份快照, 保留边界, 时间, 来源 IP), so the shared treatment is the only place
  that needed it. The `/proxy/groups` members table and every server-detail table
  (配置版本, 入站, 探测) are `DataTable` consumers and inherit the fix.

## 2. Status badges — `web/src/components/StatusBadge.vue`

`whitespace-nowrap` added to the badge root next to the existing `shrink-0`, so
"正常启用" on `/routing/services` (and every other badge) can no longer wrap one
character per line.

## 3. `/users` 到期时间

- `web/src/app/time.ts`: new `formatMinuteParts()` / `formatMinute()` — panel
  timezone, `2026/11/26 17:36` (no seconds), `''` for empty/invalid input.
- `web/src/modules/users/pages/UserListPage.vue`: the cell uses
  `formatMinute(user.expiresAt)` with `whitespace-nowrap`; the full value
  (including seconds) is still available as the cell `title`.

## 4. Server cards — 2 columns at `lg`, 3 from `xl`

- `web/src/modules/nodes/components/ServerCardGrid.vue`:
  `grid-cols-1 md:grid-cols-2 xl:grid-cols-3 2xl:grid-cols-4` (was
  `lg:grid-cols-3 xl:grid-cols-4`) so 1120 px gets two ~380 px cards instead of
  three ~250 px ones. The name row is now `flex flex-wrap` with `gap-x-2 gap-y-1`
  and the name link carries `min-w-0 max-w-full`: the region badge wraps to a
  second line instead of squeezing the name to "演示 · ...". `2xl` keeps the
  original four columns.
- `web/src/modules/system/components/NodeVersionPanel.vue` (版本与更新 card
  view): same grid change and the same wrapping name row.

## 5. Server detail 概况 — 硬件/存储/网络

`web/src/modules/nodes/components/detail/ServerSystemPanels.vue`

- Outer grid: `grid-cols-1 md:grid-cols-2 xl:grid-cols-3` (was `md:grid-cols-3`);
  the network panel spans both columns below `xl` (`md:col-span-2 xl:col-span-1`),
  i.e. 2 + 1 at 1120 px and the original 3 columns from 1280 px.
- The inner three-cell sub-grids (架构/内核/GPU, 内存/内存交换/硬盘,
  总流量/上行/下行) are `grid-cols-2 xl:grid-cols-3` and the value lines use
  `break-words` instead of `truncate`, so nothing is clipped to "1.0 Gi...".
- The CPU model no longer caps at `max-w-[180px]`, and the 实时速率 row wraps
  (`flex-wrap justify-end`) instead of overflowing.
- The parent (`ServerOverview.vue`) already passes the panels full width; no
  change was needed there beyond the `revisionEventText` import in item 6.

## 6. 最近事件 result codes

- `web/src/modules/nodes/components/detail/serverDetailModel.ts`: new
  `eventResultLabel(code)` — empty and `success` return `''` (the status already
  says 应用成功), every other code reuses `revisionResult()`, i.e. the labels of
  the 配置版本 tab (`validation_failed` → 核心校验失败, …). New
  `revisionEventText(revision)` composes `配置 #6 · 应用成功 · 手动发布当前配置`
  and appends the translated code only when it adds information.
- `web/src/modules/nodes/components/detail/ServerOverview.vue`: the events
  computed uses `revisionEventText(rev)`; the raw `${rev.resultCode || ''}`
  interpolation is gone.

## 7. Server detail 监控 — chart scale and range

- `web/src/modules/nodes/components/serverMetricsModel.ts`: `timeParts()` now
  also keeps `year` (needed to detect a day change), plus
  `formatMetricRange(start, end)` → `10/30 09:34 – 10:34` (the second date is
  omitted on the same day), `formatMetricValue(key, value)` (the same units as
  the live value: `%`, `MB/s`, plain integers, `—` when unknown) and
  `metricRangeLabel(points, key)` → `最低 18.2% · 最高 31.5%` / `最低 — · 最高 —`.
- `web/src/modules/nodes/components/ServerMetricsGrid.vue`: each card's footer
  is one wrapping line with the compact range and the min/max of the visible
  series; the exact timestamps moved to the `title`. `display()` now delegates to
  `formatMetricValue`. Data fetching, polling and the SVG geometry are unchanged.

## 8. Server detail 设置 — 默认端口分配范围

`web/src/modules/nodes/components/detail/ServerSettings.vue`: the label/hint row
is `flex flex-col gap-1 xl:flex-row xl:items-center xl:justify-between
xl:gap-3` and the label is `whitespace-nowrap`, so the hint stacks under the label
at 1120 px (352 px card) and sits beside it again from 1280 px.

## 9. Server detail 调优 — blank selects and duplicated hints

- `web/src/modules/nodes/components/detail/serverTuningModel.ts`: new
  `tuningDraft(settings)` returns a value for **every** whitelisted key (`''`
  when unset), so an empty draft matches the `<option value="">不设置</option>`.
- `web/src/modules/nodes/components/detail/ServerTuning.vue`: the initial draft,
  both presets, 载入期望配置为草稿 and the node switch all use `tuningDraft(...)`.
  `tuningRequest()` still skips empty values, so an unmapped choice is simply not
  submitted. The `<p>` hint under each input was removed — the placeholder
  (`min–max`) and the select options already carry that text.

## 10. `/nodes/versions` — disabled 升级 buttons

`web/src/modules/system/components/NodeVersionPanel.vue`: the 升级 buttons (Agent
table, core table, both card variants and the core-management dialog) add
`disabled:opacity-50 disabled:cursor-not-allowed`, and the card variants also
neutralise `hover`/`active` (`disabled:hover:bg-ios-blue/[0.08]`,
`disabled:active:scale-100`), matching the other disabled buttons.

## 11. Dashboard

`web/src/modules/dashboard/pages/DashboardPage.vue` (+ `web/src/app/time.ts`)

- (a) The date chip uses new `panelDateLabel(new Date())` (Intl with
  `authState.timezone`) instead of `getMonth()/getDate()/getDay()`, so 10月30日
  in the panel timezone is no longer shown as 10月29日 when the browser is in
  another zone.
- (b) 各节点用量排行: removed `flex-1 flex flex-col justify-around` from the rows
  container (and `justify-between` from its wrapper), so rows keep their natural
  height instead of being spread over the column height.
- (c) 用户用量与到期: new `userAttentionRank()` orders over quota → expired →
  expiring within 7 days → the rest by usage %, with disabled accounts last;
  within the two expiry groups the earliest expiry sorts first. An expired user
  can therefore no longer be pushed out of the top four by pure usage.

## 12. `/proxy/groups` members

`web/src/modules/proxy/pages/LineGroupPage.vue`: the 节点名称 cell shows the
member name and, as a secondary line, the server name (or import source) via
`memberServerLabel(node)`, so two members both called "演示 · Shadowsocks" are
distinguishable even while the 所属服务器 column is scrolled out of view. The
column itself is unchanged.

## 13. User detail — 服务有效期限

`web/src/modules/users/pages/UserDetailPage.vue`: the KPI card prints
`expiryParts.date` (`2026/11/26`) on the existing `text-lg` line and
`expiryParts.time` (`17:36`) on a smaller second line, built with
`formatMinuteParts()` in the panel timezone. Nothing is truncated at 1120 px and
the seconds-bearing `formatTime()` string is no longer sliced.

## 14. Stale wording

- `web/src/modules/system/pages/BackupPage.vue`: "完整恢复仍需核对节点账本与已消费
  额度" → "完整恢复后请核对用户额度与节点运行配置" (the per-node ledger was
  removed; quota is per user and enforced by the panel).
- `web/src/modules/access/pages/AccessRecordPage.vue`: "按凭据归属用户和设备" →
  "按凭据归属用户" (devices were removed in v1.1).
