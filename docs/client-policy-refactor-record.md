## 二、 核心重构与改动清单

### 1. 结构重构：工作台指标看板与 Tab 模块导航
* **新增配置指标看板 (KPI Summary Cards)**：
  * 在页面顶部直观展现当前客户端策略的关键参数汇总：
    * **当前运行模式**：`Rule (规则分流)` / `Global` / `Direct`
    * **混合端口 (Mixed Port)**：`7890`（带等宽字体）
    * **策略组定义数**：实时统计当前代理组数量
    * **生效分流规则数**：实时统计当前规则总数
* **新增现代化工作台 Tab 导航体系**：
  * 将原本单页冗长垂直堆叠的布局升级为模块化工作台，支持分标签专注管理：
    * **🎯 预设与运行参数**：快速预设卡片 + 4 项运行核心参数
    * **🔀 策略组定义 (X)**：专注于策略组的新增、排序、快捷节点插入与测速设置
    * **📋 分流规则列表 (Y)**：专注于规则的搜索、筛选、优先级调序与编辑
    * **📄 YAML 实时预览**：代码编辑器风格的订阅渲染结果与一键复制
  * **一键切换平铺/标签模式**：右侧提供“平铺显示全部板块”开关，兼容一滚到底的浏览习惯。

### 2. 顶部 Header 与操作控制区
* **保存状态感知（Dirty State）**：
  * 新增 `originalSnapshot` 与 `isDirty` 精确比对追踪机制。
  * 用户在页面上修改基础参数、策略组、添加/编辑/调序规则时，实时感知未保存状态。
  * 右上角“保存策略配置”按钮动态呈现未保存高亮轮廓（`ring-2 ring-ios-blue/40`）与文字提示 `保存策略配置 (已修改)`。
* **恢复默认模板防误触**：
  * 由原生浏览器的 `confirm` 弹窗升级为符合系统设计规范的 `ConfirmDialog` 弹窗组件。

### 3. 策略组定义（Proxy Groups）卡片交互大幅提升
* **快捷插入标签助手**：
  * 在每个策略组输入框下方新增常用标签快捷插入栏（`+ @all`、`+ DIRECT`、`+ REJECT` 以及其他可用策略组名）。
  * 点击即可自动去重追加至 `proxies` 字符串中，彻底解决手动打字易拼写错误的问题。
* **策略组顺序调整**：
  * 新增策略组“上移 (↑)”与“下移 (↓)”微型按钮，满足 Clash/Mihomo 客户端对策略组顺序敏感的需求。
* **高级测速参数展开面板**：
  * 当策略组类型为非 `select`（即 `url-test` 自动测速或 `fallback` 故障转移）时，支持展开高级设置：
    * 测速地址 (Test URL)：默认 `http://www.gstatic.com/generate_204`
    * 测速间隔 (Interval Seconds)：默认 `300` 秒
  * 完美对接了底层 API 已经支持但原界面未提供输入入口的字段。
* **删除保护**：
  * 保持“至少保留一个主策略组”的防空保护。

### 4. 分流规则列表（DataTable）效率优化
* **规则搜索与多维筛选工具栏**：
  * 新增按关键字过滤匹配目标（Payload）、规则类型或备注说明的搜索框。
  * 新增按规则类型分类筛选（全部 / RULE-SET / DOMAIN / IP-CIDR / GEOIP / DST-PORT / MATCH）。
  * 新增按动作目标筛选（全部 / DIRECT / REJECT / 策略组）。
  * 提供“一键清空筛选”按钮。
* **规则优先级一键规整编号**：
  * 新增“规整编号”功能，按当前表格排序自动重排为以 10、20、30... 为步长的整洁优先级，且自动保证 `MATCH` 兜底规则处于末尾。
* **规则上下调序边界保护**：
  * 抽取 `isRuleAtBound` 校验函数，首条禁用上移、末条禁用下移，并支持在筛选状态下准确定位原列表交换位置。
* **规则删除确认升级**：
  * 采用 `ConfirmDialog` 组件，带有明确的下发订阅生效提示。

### 5. 分流预设套用（Quick Presets）防覆盖保护
* **未保存修改防丢失拦截**：
  * 当用户在当前页面已有未保存的自定义规则或参数时，点击切换预设卡片会触发 `ConfirmDialog` 确认提示，告知将被预设覆盖，确认后再行应用，防止误触丢失工作成果。

### 6. 规则编辑与新建抽屉（FormDrawer）
* **表单细节优化**：
  * 当规则类型切换为 `MATCH` 时，自动清空 Payload 并无需用户手动输入。
  * 动态占位符（Placeholder）及帮助文案优化，针对不同类型（域名、CIDR、端口、GeoIP）呈现真实示例。
  * 执行动作下拉列表与当前配置中定义的策略组实时双向绑定。

## 三、 兼容性与运行保障

1. **接口契约兼容**：
   * 提交保存依旧通过 `clientPolicyAPI.save(clientConfig.value)`，参数结构与 `StoredRuleTemplate` 严格一致。
2. **错误处理保留**：
   * 保持并发冲突报错 `stale_rules` 自动重新拉取。
   * 保持服务端单字段验证报错 `invalid_rules` 精确映射为友好字段名称（`fieldLabel`）。
3. **安全与权限保持**：
   * 严格遵循 `isOwner` 计算属性，仅 Owner 权限可以保存配置与查看 YAML 订阅预览。
