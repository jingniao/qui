# v1.10.1 发布说明

## 数据整合

- 已登记节点在首次安装或升级到 v1.10.1 后执行一次旧 Agent 状态换代：删除旧本地业务状态、旧队列、旧镜像和旧运行历史，保留原节点 ID、面板配置与已入账事实。
- 换代不补传未上报数据；无法确认的未上报用量标记为数量未知，不填零。面板已接收的 pending 回执由受限内部路径继续入账。
- 迁移头从 0160 增至 0163：0161 身份换代，0162 监控分层，0163 流量分钟分层。

## 分层存储

- 用户流量保留近 24 小时原始样本，较早样本按 UTC 分钟整合并沿用账户保留期限；既有小时、日账本继续作为展示和计费来源。
- 核心流量保留近 24 小时原始样本，24 小时至 7 天使用分钟表，7 天后提升到既有小时表。
- 主机监控近 24 小时保留分钟粒度，24 小时至 7 天使用五分钟汇总，超过 7 天删除；延迟汇总保留有效中位数的样本权重和极值。
- 查询遇到已整合桶的非整点边界会返回精度错误，避免按比例猜测；迟到样本按原归属在下一次维护中合并一次。

## Agent 行为

- reset 任务使用持久 reset ID、新证书公钥和目标版本摘要幂等绑定；升级器、恢复服务和独立 reset 服务按锁顺序执行，清理未完成时不报告成功。
- 面板节点详情显示旧数据清理状态，丢弃用量显示为“数量未知”。

## 验证与范围

- 本版本不连接、不升级生产。发布前必须通过项目规定的 Linux、真实核心和 GitHub 全部门禁，并在同一提交上生成标签与附件。
