# v1.5.4 发布说明

v1.5.4 带**迁移 0143**（迁移头 0143），按 Owner 要求仍用补丁号。内容来自 v1.5.2／v1.5.3 的实机验证（[规划](v1.5.4-plan.md)第 1–12 项）：发布可靠性、节点侧完整国内名单、用户在根地址登录与管理员登录地址自定义、用户门户改版，以及 Clash 客户端导入订阅失败。

## 新增与改进

**发布可靠性**

- **按心跳确认修订**：Agent 的应用结果只存在会话内存里，会话在发出前断开就会丢失，节点一直停在「发布中」、后续发布被拒。现在面板收到新的心跳、其成功修订等于待确认修订且核心健康时，按成功确认（与应用结果走同一路径，记 INFO `deployment confirmed by heartbeat`）；失败、回滚与原因码仍只来自应用结果。
- **访问记录批次被拒时也隔离**：与流量批次共用同一实现，连续被拒 3 次后隔离、留在磁盘、不参与容量淘汰，1 小时后或 Agent 重启后重试，后续批次照常发送；控制连接不再每 30 秒断开一次。
- **面板记录拒收原因**：拒收访问记录或流量批次时记一条 WARN `agent batch rejected`（节点、种类、批次 ID、固定原因码、修订号），同一节点同种类同原因每分钟最多一条，不记录用户名或域名。
- 新增 Agent 发送顺序时序测试（应用结果先于新修订的数据）。

**节点侧完整国内名单（迁移 0143，新能力位 `native_rule_sets_supported`）**

- 规则集外部来源新增「节点原生」格式：一条来源同时给出 sing-box 二进制规则集（`.srs`）和 Xray geosite/geoip 数据文件加标签；地址只允许 jsDelivr 上的 MetaCubeX meta-rules-dat 文件，面板保存与 Agent 下载两处检查。
- 节点所有 xray/sing-box 核心都上报新能力位时，策略改为在期望状态里引用规则集文件（`match.rule_sets`），不再展开成几万条规则，也不计入匹配条数上限；旧 Agent 维持原来的 yaml 展开，保存快照与发布前两处按能力位把关。
- Agent 在应用修订、渲染之前下载文件到 `runtime/<core>/rulesets/`（单文件 32 MiB、3 分钟，只跟随白名单主机的 HTTPS 跳转），超过刷新间隔才重新下载，下载失败沿用已有文件，从未下载成功则该修订以 `rule_set_unavailable` 失败并照常回滚；切换成功后删除新修订与全部保留修订都不再引用的文件。核心自己不联网。
- 内置「国内」集合追加 geosite `cn`（约 11 万条，含 `www.qq.com`）与 geoip `cn` 两条原生来源，「屏蔽回国」策略本身不变。

**登录与门户**

- 用户在面板根地址 `/` 登录门户，旧地址 `/portal/login` 跳转到 `/`；用户详情显示可复制的门户地址（取「节点安装连接地址」里的面板地址），可一次复制门户地址与订阅链接；新建用户时可直接开启门户登录并设初始密码。
- 管理员登录地址可在「系统设置 → 安全设置」自定义（默认 `/login`，升级后不变）；面板只在该地址的页面里注入标记，其他路径显示「页面不存在」，未登录访问后台页面回到 `/`，退出回到本浏览器记住的管理员地址。忘记时在服务器上运行 `qui`，选「查看／重置管理员登录地址」。这只是隐藏入口，不改变认证、CSRF 与登录限流。
- 门户五个分区改版：概览显示流量进度、到期剩余天数与下次流量重置日期；订阅按客户端列出链接并在弹窗显示二维码；节点显示对本人开放的协议；流量改用 Chart.js 堆叠柱状图；账号显示本次登录到期时间；窄屏导航可横向滚动。登录过于频繁时提示「请求过多，请 15 分钟后再试」。门户接口只加字段（`trafficResetCycle`、`nextTrafficResetAt`、节点 `protocols`、订阅 `defaultFormat`）。

**Clash 客户端导入**

- 不带 `?format=` 的订阅链接按客户端 User-Agent 返回对应格式（Clash Verge／Mihomo Party／Clash Meta for Android／FlClash → mihomo，sing-box 官方客户端 → sing-box，v2rayN 等 → Base64，Clash for Windows → 旧版 Clash），识别不了时返回系统默认格式。
- 用户详情与门户按客户端列出各格式链接，不带格式的链接标为「自动识别」。
- 引用面板规则集时，规则集地址优先用「节点安装连接地址」里的面板地址与端口，面板在终止 TLS 的反向代理后也写 `https`。

**其他**

- 规则集页面「匹配规模」计入外部来源的缓存条目；作用于全部节点的策略保存时也检查各节点能力；延迟图在大屏下加高，图例只列有数据的目标；63 个未格式化的 Go 文件统一格式化，`quick-check.sh` 对改动的 `.go` 跑 `gofmt -l`。

## 迁移与升级注意

- 0143 重建 `service_set_sources`（新增 `native` 格式与 `xray_url`／`xray_tag` 两列，原有行保留），并给内置「国内」集合追加两条原生来源；已有原生来源或「国内」不是内置集合时跳过。备份校验接受新格式，0143 之前的归档仍合法。
- 升级后管理员登录地址仍是 `/login`；用户门户登录改到 `/`。如需隐藏管理员入口，到「系统设置 → 安全设置」修改。
- 「屏蔽回国」要用完整国内名单，节点的 Agent 需升级到 1.5.4；旧 Agent 继续用 yaml 展开的 `geolocation-cn`。
- 规则集文件新内容在下一次发布配置时生效，没有后台刷新。节点要能访问 `testingcf.jsdelivr.net`（或另两个 jsDelivr 主机）；首次下载失败时该次发布回滚，原配置不受影响。

## 已知限制

- User-Agent 匹配表按各客户端公开的写法填写，尚未在真机上逐一核实。
- 节点详情暂不显示规则集文件的下载状态与版本时间。
- 生产面板证书仍由私有 CA 签发时，Clash Verge 与 v2rayN 会报证书不受信任；需给面板配域名并用 Cloudflare DNS-01 申请公网证书，或在客户端信任面板 CA（见[1.4.1 发布说明](release-notes-1.4.1.md)）。
