# v1.5.5 发布说明

本版补齐订阅导入、服务器管理和中转方案的使用流程，增加逐出站源地址与完整清除入口。包含迁移 **0144–0148**，迁移头 **0148**；按 Owner 指定使用补丁版本号。

## 新增与改进

- 订阅：mihomo DNS 可配置引导解析、代理节点解析和过滤选项；三个「屏蔽回国」预设修正 DNS。支持更多 Reality/xhttp 输出、TUIC 和 Hysteria2 导入参数，TUIC 显式 ALPN 可往返保留；自签 TLS 的 VLESS/Trojan 等端点使用证书指纹校验。
- 服务器与总览：标签、共享排序、按公网 IP 自动识别国家；停留页面和前后台切换时刷新状态。总览按节点流量样本汇总今日／本月用量，缺测明确显示。隐藏页面暂停轮询，合并相同并发 GET，减少心跳触发的附属数据请求。
- 中转：快速创建会新建用户入口；高级画布支持新建／复用入口，保存布局保留入口绑定。发布计划展示入口、分组和路由变化。停用并移除按依赖顺序执行，保留共享资源；新建入口保存创建基线，未改动时撤除无需额外确认。内部 TLS 通道统一为 Trojan/TLS。
- 单独导入节点：稳定身份、改名、逐节点删除、跨分组／策略／画布引用及备份恢复；URL 订阅仍按来源和名称／协议管理。
- 逐出站源 IP／网卡：分别继承服务器设置，Xray 与 sing-box 按有效绑定出网；Agent 在切核前检查本机地址和网卡，无效组合明确失败并保留成功配置。服务器强制出站支持额外豁免，旧 helper 由能力门禁阻止不支持的组合。
- 运维：未发布节点升级前可先发布基础配置；隧道缺少 GOST 时引导安装；Agent 主机提供精简 `qui` 菜单，增加需两次确认的清除全部数据功能。
- 安装修复：GOST 安装成功后清理对应临时文件，避免退出阶段报目录非空；菜单成功清除安装后正常退出，取消返回菜单，失败保留原错误和非零退出码。

## 升级注意

- 先备份、升级面板，再逐台升级 Agent。迁移 0147 会转换单独导入节点的身份与引用，升级／恢复后需核对转换报告中的悬空引用；迁移 0148 为新建画布入口记录基线，旧入口仍按历史规则要求撤除确认。跨迁移降级须配套升级前数据库，见[部署与升级](deployment.md#51-面板降级与数据库回退)。
- 从 ≤1.4.7 升级 Agent，需运行两次 `qui-update --component agent`，第二次启用网页升级。新版 `qui` 菜单和本机卸载脚本也由本机更新器安装，单独网页升级 Agent 不会替换这些脚本。
- 逐出站源地址需升级 Agent。若与服务器强制出站组合使用且需要额外豁免，还需在节点运行一次 `qui-update --component agent` 更新本机 helper；仅网页升级 Agent 不替换 helper 引导程序。降级旧 helper 前须先清除需额外豁免的组合并发布。helper 从未运行且没有回执时取得首次能力的流程仍待实机核实。
- 现有客户端 DNS 配置需手动套用推荐 DNS 并保存，尚未启用的配置还须设为订阅模板；Clash Verge Rev 开启 DNS 覆写时，客户端仍可替换订阅 DNS。
- 已创建入口的分组在既有分组管理中修改，画布重新发布保留实际成员。“本次发布前出站”仅描述当前路由，撤除计划独立显示恢复目标。
- `--purge` 会删除所选组件的配置、数据库与本机备份，先将需要的备份移到清除范围之外。

## 覆盖限制与已知问题

- 浏览器共享未完成，尚无本版真实浏览器、手机／Viewer、慢网草稿、前后台两分钟及页面性能计时证据。
- 未覆盖 Owner Clash Verge Rev 的 TUN／fake-IP／DNS 覆写与真实链接；部分核心级验收不等于 GUI 验收。TLS+xhttp 的本轮真实客户端连通、Hysteria2 中转后的跳跃实流、同地址族多公网 IP 强制出站豁免及旧 helper 升级仍缺实机证据。原生 arm64 沿用此前 Owner 跳过决定，仅提供交叉构建。
- 本轮 Debian/systemd 的 purge→重装补测受容器挂载策略与只读 cgroup 限制，未执行产品安装；Alpine 仍有基础镜像缺 dev 服务、只读 cgroup 报警，未扩展宿主权限。已登记 Agent 在线连接退出、非空 nft 清除、非默认 sysctl 恢复及部分页面升级流程未实测。
- 单独导入节点与 URL 订阅后来刷新同名时，汇总保留先到端点、丢弃后者并警告；sing-box JSON 导入与客户端链输出仍不支持。
- 同入口／出口的快速方案自动命名相同，第二个方案会同名冲突；曾见撤除后立即同名创建出现一次 409，后续未复现，首因未确定。节点元数据省略 `renewNoticeDays` 时仍会清零，ACME 证书续期后撤除可能多一次确认。
