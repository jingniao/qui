## 变更内容

- 页面加载：新增用户与服务器轻量选择、批量元数据与状态接口；详情页签按需读取；新建节点弹窗并行准备所需数据；任务记录由后端分页；合并刷新请求。
- 数据库读取：显示查询使用独立只读连接池，减少等待写连接；多步查询保持短读快照；补齐恢复过程的连接关闭与重开；可选诊断区分取连接、SQL、解码及响应耗时。
- 流量存储：0154 增加流量投递确认与历史整理所需状态；按既有保留规则汇总历史样本。Agent 的新投递格式仅在本机存储基线和所有保留的回滚镜像都支持后启用，旧镜像仍在时继续旧格式，避免回滚后无法读取。
- Agent 终端升级：读取实际运行版本与受管状态，复用受管安装和恢复流程，处理本地与网页升级互斥；保留禁止降级、失败恢复和离线签名校验。
- 数据库缩容模式保持原值，升级不主动执行完整 VACUUM。

实现与边界见[页面计划](superpowers/plans/2026-11-18-page-loading.md)、[流量存储计划](superpowers/plans/2026-11-18-traffic-storage-retirement.md)、[终端升级计划](superpowers/plans/2026-11-18-qui-managed-agent-update.md)。
