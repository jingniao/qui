# v1.7.1 发布说明

无新迁移，迁移头保持 **0154**。Owner 已批准将受管 Agent 终端升级修复、生产复测发现的总览慢查询及卡片加载状态一并纳入本版。

**发布和生产部署成功，性能验收尚未全部通过。** 用户接口明显改善，但总览接口 20 次实测 p50 15.876 秒、p95 23.429 秒；页面三轮为 7.480 / 14.120 / 44.117 秒，第三轮第一次请求超时后等到自动刷新才恢复。月流量仍需进一步优化，不能把本次改进记为总览慢加载已解决。

## 修复

- 终端升级：本地候选文件验证签名后登记接受记录，再进入安装事务；预检仍只读，不提前接受签名。修复 v1.7.0 实机升级的 `preflight_failed`。
- 总览流量：整秒范围按索引读取，只有起止秒含纳秒时才精确比较边界秒，避免反复处理整个月的时间字符串；保留混合秒/纳秒格式、左闭右开范围、节点过滤和小时历史精度约束。
- 总览显示：待处理问题、节点流量、用户用量与到期、近期阻断及实时概况在数据等待或失败时保留标题与明确状态，不以空白卡片代替。Owner 权限与原有内容保持。
- 服务器列表：浏览器后台期间的旧心跳不再被判成全体离线；恢复时显示“状态待更新”，新响应才重新判断状态，并丢弃跨后台周期的晚到响应。真实离线、禁用和待登记状态仍保留。
- 整机流量：补齐独立只读节点仓库的时区读取依赖，修复批量与单台整机流量接口的 500。

候选实际 Go 查询代码在生产以面板账号、只读连接单独执行：固定月窗口 5.446 秒、日窗口 0.327 秒、小时趋势 0.338 秒；未替换生产面板程序或修改配置。整机流量接口的既有只读隔离回归加入该路径后，修复前确实返回 500，补齐依赖后返回 200且未等待主写连接。后台恢复状态回归观察到修复前错误判定 offline，修复后 unknown，收到新数据后恢复 online 或真实 offline。
