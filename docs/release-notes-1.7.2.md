## 变化

- 服务器运行状态用白名单快照和 SSE 更新，前台恢复时保留完整卡片；轻量校准修正漏掉的事件，真实离线仍正常显示。展示刷新由后台队列处理，不阻塞 Agent 心跳确认。
- 新增可重建的代理流量小时索引：完整小时读取汇总，时间边界读取原始样本，保留来源切换、去重、补传、溢出错误与压缩历史的精度限制。原始流量账本和用户额度计算不变。
- 后台统一准备日／月／趋势／整机统计，总览、服务器列表与详情复用同一版本。配置改变使旧结果失效；失败明确报告原因，适用时保留上次完整结果及其截止时间。
- 总览基础内容与流量统计分开读取，保留待处理问题、节点流量、用户用量与到期、近期阻断。四张内容卡片固定为 480px，长列表内部滚动，标题保持可见。
- 服务器详情按节点读取统计；修复清单刷新失败后不重试、调优建议过期、跨页旧账期缓存和夏令时跳过午夜的日期边界问题。
