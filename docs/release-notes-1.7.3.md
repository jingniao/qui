# v1.7.3 发布说明

状态：2026-11-19 正式发布，随后按 Owner 授权部署生产面板及德国 netcup、美国 CC、美国 shlii.io Agent。无数据库迁移，迁移头保持 **0155**。完整结果见[生产部署与性能复测](v1.7.3-production-acceptance.md)。

## 变化

- 代理节点页的普通心跳只更新运行指标，配置变化再重读；入站发布状态只比较真实监听、证书和链路，省去用户凭据、策略及调优建议的无关计算。
- 用户列表、详情的主资料与辅助选项独立加载；新建节点弹窗复用当前页列表，高级选项按需读取。保留流量账本、额度口径和当前卡片显示。
- 修复面板高 CPU：Agent 控制连接获取能力时不再反复读取并排序最近 24 小时的延迟记录。生产升级前平均 CPU 79.55%，升级后两组为 68.64%、32.97%；同期有其他管理操作，负载不完全一致，仍有 HTTP 列表/延迟接口计算调优建议的热点。
- 已登记服务器可以再次生成安装命令。同机覆盖先停止旧 Agent 并上传最终数据，面板确认后才删除旧 Agent 本机数据；失败保留数据。新机接替是单独选项，新登记成功后旧证书失效，面板记录、配置和流量历史均保留。默认保留原主核心顺序。
- Agent 运行日志限制为 10 个文件、每个 10 MiB，总计 100 MiB；不清理流量队列。需更新并重启监督程序，单独网页升级 worker 不会使旧监督进程获得日志限额。

## 安装边界

同机覆盖要求旧服务正常停止、最后采样可确认，并且新面板端点实际接收和确认补传。自定义数据路径、CA 或不安全文件引用在停服前拒绝。OpenRC 需要已安装 `strace` 且允许观察进程退出；缺少时拒绝停服，不自动安装。新机接替不上传或删除另一台旧机器上的本地数据。
