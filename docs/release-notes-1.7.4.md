# v1.7.4 发布说明

## 内容

- 降低节点展开、延迟读取和调优状态轮询中的重复建议计算；SQLite 只读连接最多保留两个空闲连接，并发上限仍为四。
- 代理节点批量读取中转展示规则，复用同一数据版本的在途读取；用户详情按依赖并行加载，减少串行等待。
- 多页面刷新保留已确认的卡片和内容；账号、权限、查询或节点失效时清理对应状态，防止迟到响应回写。保留流量统计口径和现有卡片布局。
- 调优发布显示受理、请求接替、执行失败和未确认结果。固定辅助程序以实际权限探测 19 个白名单写入口，探测回执绑定当前开机与辅助程序身份。
- Owner 可为单次调优允许补装与当前运行内核精确匹配的 Ubuntu 官方 BBR/fq 独立模块包。包结果与参数应用结果分别确认，普通建议和恢复不触发安装；不更换内核、不重启。
- 修正调优服务的开机顺序、旧版本回滚后遗留探测、包事务中断后的恢复说明，以及包忙时卸载提前停止 Agent 的问题。

## 迁移与升级

新增 **0156**，仅在 `node_tuning` 保存该次补装意图。没有修改既有迁移、流量表或统计时间边界。版本号按 Owner 指定采用 v1.7.4。

补装限 Ubuntu/systemd、amd64/arm64，需要宿主已有 Python 3.9+、发行版包工具和可信 archive keyring。只有受支持的当前内核独立模块包会安装；混合内核镜像包、无法证明匹配、容器及缺入口/权限受限的环境会明确拒绝。仅更新受管 worker 不会更新固定辅助程序和服务单元，启用新增探测与补装能力需完成本机 Agent 安装组件升级，见[部署说明](deployment.md)和[运维手册](operations.md)。

发行版模块维护脚本可能更新当前内核的模块索引、initramfs 与引导菜单。已开始的包事务应等到终态后再升级或卸载；中断收尾必须按运维手册核对请求身份，不自动重试装包。
