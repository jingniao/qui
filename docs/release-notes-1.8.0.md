# v1.8.0 发布说明

## 功能与修复

- 入站可指定出口 IP，覆盖服务器和出站绑定，支持 Xray 与 sing-box；GOST 和缺少能力的 Agent 明确拒绝。新增迁移 0159。
- 每个出口 IP 独立探测、独立选路，保留主备、延迟、轮询及失败策略。未知健康不借用默认出口结果，全部原始成员继续探测，面板只上报默认出口健康，访问与统计沿用原业务 ID。
- 修复启停入站、重新发布用户访问时清空出口 IP；不支持该能力时仍可清除旧设置。
- Agent 处理 TCP 探测命令和结果时保留心跳定时器，避免额外心跳轮次。
- 离线通知使用共用确认规则，维护节点不发离线通知，订阅排除任一禁用受管跳；通知开关只控制通知，离线时限仍供界面与订阅使用。
- 面板通知 worker 启动后，先按配置离线时限重新观察（至少 45 秒），再创建新离线告警；保留已有事件、去重和恢复通知。
- 通知框改为实色背景、320px 宽，每次打开默认只看未读；批量升级 Agent 直接使用最新可用正式版。
- 修复总览同步层在新 SSE generation 校准期间反复作废在途请求的问题；旧代 HTTP 响应被拒绝后立即重读。此前生产总览持续误报离线的根因尚未完成现场确认。

## 兼容与迁移

迁移头从 0158 升至 0159，仅为 inbounds 增加非空、默认空字符串的 egress_source_ip。
最低兼容版本仍为 v1.7.5，旧备份跳过不存在的新列校验，保留有效数据与在途任务。
新能力须在面板和 Agent 升级后使用。未设置入站出口 IP 时，既有配置黄金对照保持字节一致。
跨迁移降级需使用匹配的升级前数据库。
