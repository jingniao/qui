# v1.10.4 发布说明

## 改进与修复

- 节点展示、订阅和离线通知使用同一份进程内连接存活事实。已认证连接有消息等待数据库或确认时，避免把面板处理延迟误报为节点离线；接收错误与连接取消独立撤销存活证据。
- 列表、卡片和详情在处理超过 10 秒后持续显示延迟，日志每 60 秒重复记录；浏览器证据 45 秒过期并触发重新校准。保留核心异常、降级状态和指标的真实持久化时间。
- 新增独立 Go 工具 `qui-update-db`，接管更新器的数据库复制、逐字节比较和备份预检。保留面板账号读取、文件及目录同步、固定目录句柄发布、目标版本检查程序。
- 工具随双架构程序包发布，由面板和 Agent 共享安装；更新开始前固定副本，并随面板快照保存摘要。恢复使用快照副本，已安装工具缺失或替换不影响合法恢复；快照工具损坏明确拒绝恢复并保留现场。

## 兼容与范围

无新迁移，迁移头保持 0163；最低兼容 v1.7.5，保留有效数据与在途任务。控制准入、Agent 协议、数据库心跳与指标时效保持原规则，不提前 Ack。

旧安装首次更新仍由其已安装 updater 执行，Go 工具从新脚本的后续运行接管数据库操作。B3 本次只交付数据库文件链路，journal、快照状态机与 JSON 事件仍由 Bash 负责。
