# v1.12.0 发布说明

## 修复

- Agent、旧 worker 或代理核心升级任务不再阻止签发重装恢复码；配置发布与核心移除仍按原规则阻止安装。
- 成功核销恢复码、切换节点身份时，在同一事务内将该节点尚未结束的升级任务标为 `superseded`（已由重装接替），解除旧任务对配置恢复的占用。仅签发恢复码、普通重连或核销失败不改变旧任务。
- 保留旧任务请求、执行阶段、真实结果、尝试与日志；该状态只表示面板协调任务已由重装接替，不表示远端安装已取消或执行成功。
- 三类更新领取命令时在同一事务内核对身份；旧身份、迟到回执及旧任务重试不能重新激活被接替的任务。
- 任务记录支持状态显示、筛选和中文搜索；归档校验与备份恢复保留旧执行证据，不重新激活旧升级。

## 迁移与兼容

新增迁移 `0165_reinstall_superseded_updates.sql`，迁移头为 **0165**；重建相关任务表以扩展状态约束，保留六张表的已有数据、外键和活跃任务唯一索引。最低兼容 v1.7.5，保留其有效数据与在途任务。上一版本 v1.11.0 已包含迁移 0164，本版本不修改旧迁移。

本次修复面板的安装准入与重装协调流程。远端已经损坏的 Agent 仍须完成实际重装；本版本不自动修复远端文件，也未修改页面离线闪动逻辑。
