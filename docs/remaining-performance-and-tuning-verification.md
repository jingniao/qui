## 用户详情

只依赖用户 ID 的订阅、预览、流量和访问读取与主资料同时启动，用户专属结果仍等当前主资料确认后采用。依赖用户名的操作记录保持原顺序。普通同用户刷新保留卡片、地址、链接和二维码，读取错误独立显示；换用户或明确拒绝则立即清空，包括已打开的编辑抽屉及复制到表单里的字段。

新增精确移除指定在途 GET 的操作。明确失效时清理本用户的主资料、活动、链接和预览共享请求，避免重试再次接受失效前的响应；其他请求继续合并。重置成功后的链接/预览读取错误有 GET-only「重新读取」按钮，恢复时无需再次重置凭据。

用户加载行为测试 35 项通过，包含辅助接口先拒绝、切用户、写操作迟到、主资料与重置交错、普通网络失败和只读重试。背景刷新、页面生命周期及类型检查通过。独立审查发现的权限边界和恢复问题均已补 RED/GREEN 回归，定向复审通过。错误区的「重新读取」调用整页只读刷新，沿用手动刷新同步门户开关的现有行为；自动重新确认仍保留未保存的门户开关编辑。

## 刷新稳定性

同资源刷新或普通读取失败时，列表、系统卡片、服务器详情子表、门户和画布保留已确认的内容，错误仍显示。切换账号、角色、资源或查询时清理对应内容。服务器清单与保存顺序同时提交，元数据在同一账号内也比较读取与保存的先后，旧读不会覆盖刚保存的地区和备注。

审查修正了并行读取中后到权限拒绝被遮住、旧画布创建回包跨会话写入、旧元数据覆盖新保存、删空末页后失去分页入口、出站未知显示零，以及访问详情抽屉残留。相关六项行为测试先 0/6 失败，修正后 6/6 通过，抽屉和旧画布提示另有直接检查。原先 11 项新增刷新用例分次通过；相关导航、元数据、用户及画布脚本通过。修正后类型检查通过，独立定向复审确认 6 项均解决。

并行读取的普通错误等待同批其他读取结束或原超时后展示，明确的 401/403/404 立即传播。这样避免先到的暂时失败遮住后来的权限拒绝。没有改变流量缓存跨日、时区、网卡及恢复时的强制失效，也没有改变统计口径。

## 调优反馈与权限探测

调优状态不再等待建议接口。发布前确认实际发送的完整配置，受理后清掉上次结果，显示请求 ID 和等待状态；真正失败时就近显示原始原因。另一会话发布新请求后，页面接管权威状态并提示请求已替换，旧响应不能恢复旧状态。终态刷新节点能力，保留原有参数事务回滚。

新 Agent 使用实际辅助程序的探测结果。19 项权限只打开写入口，不写入；回执必须匹配当前开机及固定辅助程序。缺少、损坏或不匹配时拒绝新设置。旧 Agent 保留已有行为，明确说明权限为估算，不广告模块补装能力。容器缺少 fq 设置入口与没有模块分别说明；设置默认排队算法不等于更改已有网卡的排队规则。

调优探测的阶段性验证：隔离 Debian 12/systemd 运行候选 helper，使用与正式应用相同的权限约束，只打开 19 个白名单写入口，不写参数。探测回执可由 Agent 读取，19 个参数、现有调优配置、旧请求和执行结果均未改变。另用真实只读挂载及受限文件验证 EROFS、EACCES 和无法查询路径的分类；EPERM 未单独注入。

安装与恢复检查发现并修正了开机恢复等待后续服务造成的互等、OpenRC 交互回滚重放旧请求，以及同次开机遗留探测结果的问题。独立 systemd 恢复服务调用真实回滚路径，确认恢复退出后探测与监听正常启动；相关部署检查 80 项、更新检查 37 项通过。后续补充的辅助程序摘要绑定及五个生命周期场景在 Linux `-race` 下通过（tuning 1.177 秒、control 1.120 秒）。原样提取 v1.7.3 更新器并执行其旧恢复函数后，新 worker 会拒绝旧辅助程序对应的遗留回执。旧更新器仍会留下新探测单元及摘要文件，恢复的旧服务不拉起这些单元；旧卸载器也不会识别这些新增文件。

普通重启另有直接验证：同次开机、同一个辅助程序先探测成功，再人为使 systemd 创建探测环境失败（226/NAMESPACE，尚未执行程序），worker 拒绝新设置；修复测试环境后恢复就绪。前置步骤仅以 Agent 账号删除固定回执，探测权限不扩大。OpenRC 普通启动与自动拉起也报告 pending/ready/failed；代码与脚本回归通过，未在原生 OpenRC 主机重启验证。此轮 Linux 三包 `-race` 通过（1.206、1.007、1.115 秒），正式 helper 场景通过，参数与原有请求/结果未改变。第一次正式夹具未能制造预期故障，已修正挂载路径后重跑通过，原断言保留。调优探测的第二轮定向复审已通过，没有遗留阻塞问题。

首版限定 Ubuntu/systemd、amd64/arm64 的官方独立模块包，宿主须已有 Python 3.9+ 和包工具。程序内嵌于 Go Agent，只使用 Python 标准库，不另行下载脚本或安装解释器。运行 release、构建、架构、官方签名索引、归档摘要、包身份和模块清单全部匹配后才安装；容器、缺入口、不可写或无法证明匹配时给出原因。不会更换运行内核或重启。正常发行版维护脚本可能更新当前内核的模块索引、initramfs 和引导菜单。

包阶段与参数阶段分别等回执。上一笔包事务尚未完成时，新请求也等待其终态，避免模块文件刚出现就提前应用；参数应用仍完整校验、写入、读回和回滚。已配置包名保留展示，参数失败不伪装为整项成功。网页 15 分 30 秒后停止自动轮询并显示未确认，可手动刷新迟到结果。卸载遇到包事务忙时恢复模块监听，保持 Agent 原有运行状态。
