# v1.5.0 P4：规则集外部来源与关键字 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 规则集（`service_sets`）可添加外部来源（HTTPS 链接，yaml／text／mrs），客户端（mihomo）直接引用，节点策略使用面板解析后的缓存；新增「关键字」条目类型。

**Architecture:** 迁移 0140 重建条目表加入 `keyword`，新增 `service_set_sources`。policy 模块通过注入的 `SourceFetcher` 接口复用 `subscription/importer.Fetcher` 的安全抓取（不产生包依赖环），解析结果密封缓存在来源行；`Service.resolve` 展开规则集时并入缓存条目。`desiredstate.Match` 新增 `Keywords`，Xray 渲染 `keyword:`、sing-box 渲染 `domain_keyword`，由新能力位门禁。mihomo 导出为每个外部来源追加一个 `rule-provider` 与同目标的 `RULE-SET` 行。

**Tech Stack:** Go（`internal/panel/policy`、`pkg/contracts/policy`、`pkg/contracts/desiredstate`、`internal/agent/core/{xray,singbox}`、`internal/panel/subscription`）、SQLite、Vue。

**Spec:** `docs/v1.5.0-plan.md` §9；总索引的 Global Constraints、proto（Capabilities 27、CoreCapability 13）与迁移（0140）登记。

## Global Constraints

- 每个规则集最多 10 个外部来源；URL 只接受 `https://`（复用 `importer.ValidURL`）；抓取限制沿用 importer（2 MiB／15 秒、公网 IP 固定、固定错误码）；解析后每个来源最多 20000 条，超出部分计入「已跳过」。
- 格式 `yaml|text|mrs`，行为 `classical|domain|ipcidr`；`mrs` 只能配 `domain|ipcidr`（mihomo 规定），且「节点可用」恒为否。
- 刷新间隔 3600–604800 秒，默认 86400；保存来源后立即异步抓取一次；失败保留上次成功缓存（`last_status=failed`），节点发布使用最近一次成功缓存。
- 关键字：1–253 字节、不含逗号、空白与控制字符、全部小写；单个规则集手写关键字最多 1000 个。
- 节点只要有一个启用的 Xray/sing-box 核心未上报 `domain_keyword_supported`，带关键字的策略在保存草稿、快照与发布前三处一致拒绝（错误码 `keyword_unsupported`，中文提示「该服务器的 Agent 不支持关键字规则，请先升级 Agent」）。

## Review Focus

- 外部文件含 BOM、CRLF、注释、空行与行尾 `,no-resolve`：都能正确解析——Task 2 的 `TestParseClassicalListTolerantFormat`。
- 外部文件 2 MiB 内但 3 万条：截断到 20000 并报告跳过数，不拒绝整个来源——Task 2 的 `TestParseCapsEntries`。
- 来源 URL 返回 HTML 错误页（200）：解析得 0 条有效项 → `last_status=failed`、`last_error_code=parse_empty`，保留旧缓存——Task 3 的 `TestRefreshKeepsCacheOnEmptyParse`。
- 规则集被禁用：外部来源不进节点、mihomo 仍按现有规则提示禁用——Task 4 的 `TestDisabledServiceSetSkipsSources`。
- 旧 Agent + 关键字：三处一致拒绝而不是静默丢掉关键字——Task 5 的 `TestKeywordRejectedForOldAgent`。
