# v1.5.0 P6：Hysteria2 端口跳跃 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hysteria2 入站可设置一段跳跃端口：节点用 nftables 把这段 UDP 端口重定向到入站监听端口，订阅按各格式输出跳跃参数。

**Architecture:** 先在本地测试机实测（Task 1），不通过就停。通过后：`desiredstate.QUICSettings` 增加跳跃字段并由能力位门禁；面板端口冲突改用新的 `ClaimedPorts`（含跳跃段），Agent 的监听预留仍用 `ListenPorts`（跳跃段没有真实监听）。nft 规则由**现有的强制出站 helper**（`proxy-agent --apply-host-network`，同一个 CAP_NET_ADMIN 单元）多维护一张表 `inet proxy_agent_hop`，不新增单元，因此不改安装记录格式。订阅导出 mihomo `ports`/`hop-interval`、sing-box `server_ports`/`hop_interval`、URI `mport`。

**Tech Stack:** Go（`pkg/contracts/desiredstate`、`internal/agent/hostnet`、`internal/agent/reconcile`、`internal/panel/proxy`、`internal/panel/subscription/format/*`）、nftables、Vue。

**Spec:** `docs/v1.5.0-plan.md` §7；总索引的 Global Constraints 与 proto 登记（Capabilities 28）。

## Global Constraints

- 仅 Hysteria2 **入站**、仅 sing-box 核心；跳跃段 `hop_port_start`–`hop_port_end` 为 1–65535、`end > start`、最多 10000 个端口、不得包含入站自身端口；`hop_interval_seconds` 5–300，默认 30（只用于订阅）。
- 能力位 `Capabilities.port_hop_supported`（28）= Agent 新版本且 `hostnet` helper 已安装；面板保存、快照与发布前三处一致拒绝（`port_hop_unsupported`，提示「该服务器的 Agent 不支持端口跳跃，请先升级 Agent」）。
- nft 规则只写表 `inet proxy_agent_hop`，链 `prerouting`（`type nat hook prerouting priority dstnat`），每个入站一条 `udp dport <start>-<end> redirect to :<port>`；整表替换（先 `delete table` 再建）；没有跳跃入站时删除该表。不碰任何其他表。
- 订阅：mihomo `ports: "<start>-<end>"`、`hop-interval: <秒>`；sing-box `server_ports: ["<start>:<end>"]`、`hop_interval: "<秒>s"`；URI 查询参数 `mport=<start>-<end>`；legacy Clash 本来就不输出 Hysteria2。
- 编辑器说明：NAT 主机的跳跃段必须在服务商放行的端口内；主机防火墙需放行该段 UDP。

## Review Focus

- 两个 Hysteria2 入站的跳跃段重叠，或跳跃段压到别的入站端口上：面板保存拒绝 `port_in_use`——Task 3 的 `TestHopRangeConflicts`。
- 删除最后一个跳跃入站后：nft 表被删除——Task 4 的 `TestRenderWithoutHopsDeletesTable`。
- 配置回滚到不含跳跃的旧修订：nft 表随之删除；回滚到含跳跃的修订：表恢复——Task 4 的 reconcile 测试。
- 强制出站与端口跳跃同时启用：两张表互不覆盖——Task 4 的 `TestRenderKeepsSourceAndHopTables`。
- Agent 重启或主机重启后：helper 的 .path 单元重放 desired，规则恢复——Task 6 测试机验证。
