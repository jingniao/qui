# 总览服务器价值与日汇率实施计划

**目标：** 按 Owner 确认，将总览「核心运行」替换为服务器总价值、月均支出、剩余价值，并提供统一币种换算与今日汇率。

**范围：** Owner 本次明确授权新增后端汇率接口；不修改数据库、部署脚本和 state，不连接生产，不暂存或提交 Git，按此前要求不新增或运行测试、类型检查和构建。

**实现方式：** 沿用 Go dashboard 模块和 Vue 公共组件。汇率来自 `https://open.er-api.com/v6/latest/CNY`，只请求固定人民币基准，不发送服务器资料；按供应商下一次更新时间缓存于内存，失败直接展示，不使用固定汇率或过期缓存。币种支持沿用服务器续费表单的八种币种，默认 CNY，换算公式为「原金额 ÷ 原币种汇率 × 展示币种汇率」。

**统计口径：** 全部未删除服务器，包含离线、维护和停用服务器。总价值为已填写的续费价格之和，表示各服务器一个续费周期的登记价格，并非历史累计付款；月均、剩余价值复用 `calculateMonthlyExpenditure`、`calculateResidualValue`。未填写价格不计入；一次性费用不计月均支出，无法计算剩余价值时明确标示未计入；已到期的周期付费服务器剩余价值为零。显示实际汇率日期和来源。
