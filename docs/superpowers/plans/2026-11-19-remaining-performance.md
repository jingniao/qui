# 剩余性能优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. 不提交、不推送、不发布部署。

**Goal:** 完成已确认三项优化，并验证只读数据库连接复用。
**Architecture:** 去掉无关计算，批量展示读取，按数据代次合并在途请求；不缓存最终授权/流量判断。
**Tech Stack:** Go、SQLite、Vue 3、TypeScript、现有自测脚本。
**Spec:** `docs/superpowers/specs/2026-11-19-remaining-performance-design.md`

## Global Constraints

- 在当前目录修改，不覆盖已有改动；不暂存、提交、推送、发布、部署。生产访问仅限用户随后指定的 shlii.io 美国 1元节点 BBR/fq/调优受控实机测试，不触及面板和其他节点。
- 保留流量统计准确性、真实授权/发布状态和现在的卡片显示。
- 性能与刷新优化不修改数据库迁移、账本、额度判断、时间窗口和 UI 布局。后续获准的 Task 6 仅可新增保存模块补装意图所必需的字段迁移，不触及流量表。
- 用户已允许新增和运行相关回归测试；优先最窄检查，失败不得弱化断言。
- 查询错误明确暴露；过时响应不得覆盖新数据；不把未知或失败显示为成功。

## Review Focus

- 订阅撤权、维护、到期/额度判断保持；窄读取仍包含核心能力和必要连接字段。
- 只读连接复用后，恢复/回滚不能访问旧库；取消不得泄漏事务或阻塞写入。
- 状态查询在途发生真实修订变化时，不能复用旧代次结果；筛选缩小时无需全量重查。
- 批量中转结果与旧规则显示一致，Viewer 权限不扩大，创建后的分享链接保留。
- 用户切页、主资料失败或辅助失败时，不串用户、不隐藏错误、不清空正确卡片。
