# v1.2 浏览器走查修复 A

日期：2026-10-29。仅修改本报告列出的前端文件及自检，没有提交代码。保留 Owner 的布局与样式；没有修改指定的并行编辑文件、internal/、migrations/ 或 Go 依赖文件。以下为本次修改范围，不代表工作区其他既有修改。

## 修复项目与决定

1. **总览用户、节点和发布提醒**（web/src/modules/dashboard/pages/DashboardPage.vue）
   - ProxyUser 以 status 表示启用状态，没有 enabled 字段。徽标先判断非 active，显示灰色“已停用”；到期再显示“已过期”，然后判断超额。
   - 有效用户仅统计 active、未到期且未超额的用户。待关注仍统计 active 用户的超额或七天内到期，每个用户最多一次，排除停用用户。
   - 在线仅包含启用、未删除、非维护且状态为 online/degraded 的节点。pending 显示“待登记”，排名圆点为灰色；待登记提醒可达。健康核心计数要求明确上报 core_healthy=true，缺测不冒充健康。
   - 按节点选择最大修订 ID 的已完成结果（success/failed 或 success/error 结果码），忽略草稿等未完成状态，只提醒最新结果中的失败。成功之后的历史失败不会继续提醒，同节点旧失败也不重复提醒。
   - 节点标签依次使用 dashboard.nodeNames、节点列表名称、前八位 ID。链接为 /nodes/<nodeId>?tab=revisions。

2. **移动端导航遮挡**（web/src/layouts/MainLayout.vue）
   - 小于 lg 时主内容顶部预留 4rem，普通页与流式画布页均覆盖；lg 恢复原有顶部间距，桌面布局不变。

3. **中文时间与面板时区**
   - web/src/modules/nodes/components/ServerMetricsGrid.vue 和 web/src/modules/nodes/components/detail/ServerTuning.vue 使用 app/auth.ts 的 formatTime。
   - web/src/modules/nodes/components/serverMetricsModel.ts 保持 formatTimeHMS/HM/MD 签名，使用 Intl.DateTimeFormat、authState.timezone 与 h23，正确处理时区跨日和午夜 00 点。
   - web/src/portal/PortalPage.vue：门户 Profile/Session/Snapshot 均未提供时区，管理员 authState.timezone 在门户会话中没有可靠来源。因此选择明确的 zh-CN、24 小时制和浏览器时区回退，不读取管理员会话默认或残留时区。无效日期显示“—”。

4. **当前指标缺测提示**（web/src/modules/nodes/components/ServerMetricsGrid.vue）
   - 离线、缺少有效心跳、心跳超过 45 秒或未来偏移超过 5 秒时，当前值显示“—”，提示“服务器离线，当前值不可用”，历史曲线仍保留。
   - 在线且心跳新鲜但字段缺失时，显示“需要新版 Agent 上报”，删除未发布的版本号。

5. **单服务器设置与重启说明**
   - web/src/modules/nodes/components/detail/ServerSettings.vue 传入 fixed-node-id。
   - web/src/modules/system/components/CoreUpdatesPanel.vue 预选当前服务器、隐藏目标选择器，服务器 ID 变化时同步；通用用法保留选择器。
   - web/src/modules/nodes/components/NodeRestartPanel.vue 删除说明和确认弹窗中的授权账本、剩余额度重编译、未知消费保护说法。
   - 只读核对实际重启 API：要求新鲜心跳、启用且在线/降级、支持重启、成功且未变化的当前修订；发布、回滚、核心更新等占用拒绝，已有待确认重启在 UI 阻止重复操作。文案反映这些条件及连接中断、等待回执，不改动后端。

6. **版本与更新的登记限制、架构显示**（web/src/modules/system/components/NodeVersionPanel.vue）
   - NodeVersionsPage.vue 实际嵌入此组件，因此不需直接修改入口页。
   - 列表、卡片和内核管理弹窗的升级按钮在没有 Agent/有效心跳、未登记、离线、停用、已删除、心跳过期或无当前配置时禁用，title 说明原因。
   - 架构优先读取 capabilities.host.architecture，回退旧 architecture/platform 字段；未知仍为“—”。

7. **任务记录内容顺序**（web/src/modules/system/pages/TaskRecordPage.vue）
   - “Agent 签名发布目录”移到标题和筛选栏后，内容及操作保留。

8. **连接控制徽标**（web/src/modules/users/pages/UserDetailPage.vue）
   - 使用 user.deviceLimit：0 为“不限设备”，其他值为“最多 N 个地址”；流量卡的重置周期保持原样。

9. **节点分组命名统一**
   - web/src 中的 15 处旧称均改为“节点分组”，不改代码标识符。
   - 文件：web/src/modules/nodes/pages/NodeListPage.vue、NodeDetailPage.vue；web/src/modules/nodes/components/ServerDeleteDialog.vue；web/src/modules/proxy/components/node-editor/NodeAdvancedFields.vue；web/src/modules/proxy/pages/OutboundGroupPage.vue；web/src/modules/routing/pages/ClientPolicyPage.vue、RoutingRuleEditorPage.vue、RoutingRulePage.vue；web/src/modules/system/components/RestorePreviewPanel.vue、RuntimeSettingsPanel.vue；web/src/modules/system/pages/RevisionPage.vue；web/src/modules/users/pages/UserDetailPage.vue。
