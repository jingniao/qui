# S3: public Reality client model and import/export codecs

Implemented on the S1 baseline `ccf23e4`; this report records the phase scope,
not release acceptance. The root assistant reviewed the model and capability
boundaries before the local phase commit. No source was fetched and no running
node was changed.

The shared public model adds `TLS.ClientFingerprint` (separate from certificate
pin `TLS.Fingerprint`), `Proxy.Reality` with public key and optional Short ID /
SpiderX, and the typed `Transport.XHTTP` shape for the next phase. New absent
fields use JSON omission to preserve existing cache content identities. There
are no server private keys in these types. `ValidateClientSettings` is reused by
imports, exporters and backup verification; the package remains independent of
DesiredState and panel services.

URI/Base64 and Clash imports accept VLESS Reality TCP with empty flow or Vision,
and Reality gRPC without flow. Validation covers canonical X25519 public keys
and low-order values, UUIDs, omitted versus explicitly empty Short IDs, client
fingerprints, aliases/repeated parameters, `encryption=none`, and incompatible
settings. Diagnostics contain fixed messages and field paths. The S1 malformed
result case `diagnostics:null` (or omitted) is now rejected.

URI output preserves the public connection settings, ALPN and optional SpiderX.
Mihomo and sing-box output is limited to the S0-measured Reality TCP Vision
combination, with unmeasured Reality combinations and SpiderX omitted individually.
Invalid internal Reality material remains an error. Format filtering retains
chain dependency cleanup and explicit REJECT empty-group behavior.

## Verification and limits

- Uncached `go test ./internal/panel/subscription/...` passed on Windows.
- Focused Reality, ordinary TLS fingerprint/pin distinction, canonical cache
  identity, result-validation and import-backup tests passed. Actual archive
  Create/Examine tests preserve gRPC service names, explicit empty SID, fingerprint
  and SpiderX, and reject an invalid Reality key.
- `git diff --check` passed.
- The full backup suite encountered Windows `Access is denied` failures in
  existing Canvas / restore-stage tests. Focused import-backup tests passed.
- GR02 verifies codec fidelity for `serviceName=s0 grpc`, including percent
  encoding and parsing. It is not URI-consuming-client evidence.
- Generated S3 Mihomo/sing-box Reality output has **not yet been exercised in
  authenticated HTTP tests**. S0 measured the underlying combination; later
  real-core regression tests must consume these exporters' actual output.
- No Linux gate, browser walkthrough, real-source fetch, production test, or
  overall S5 acceptance was performed. xhttp parsing/output remains S4.
