## 3. 发现的问题与处理

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 侧栏展开时，通知面板向左伸出窗口，标题和每条通知开头被截断 | 面板相对铃铛右对齐（`right-0`），铃铛在侧栏右侧（x≈210），面板宽 384px，向左越过窗口约 170px | 展开状态下改为相对侧栏定位（`left-3 top-14`），宽度上限 `100vw-1.5rem`；收起侧栏的位置不变。复测：桌面 1600px 面板位于 x=12–396，移动 390px 位于 x=12–332，都在窗口内 |
| Viewer 的通知面板显示“全部标为已读”，点击会 403 | `POST /notifications/read-all` 仅 Owner，按钮只看未读数 | 按钮改为 `isOwner && unreadCount > 0`。复测：Viewer 看不到，Owner 仍可见 |

两处都只改 `web/src/components/NotificationBell.vue`，在 `web/scripts/notifications-selftest.mjs` 增加回归断言；`npm run typecheck` 与该自测通过，修复后重新构建面板并完整复跑走查。
