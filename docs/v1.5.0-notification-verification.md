## 搭建与证据规则

开始时隔离面板与容器未运行，门禁进程检查为空。启动前用 SQLite backup API 复制数据库为 `panel-db-before.db`，并记录 lsmod、全部 `net.*` sysctl、nft、ip link/addr 基线。
