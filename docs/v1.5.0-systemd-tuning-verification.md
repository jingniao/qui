辅助脚本 `/root/qui-sysctl-accept/submit.py` 以如下方式模拟 Agent 原子请求，随后最多 30 秒轮询匹配 request_id 的回执。Python 代码通过 `runuser -u proxy-agent -- python3 -c <代码> <JSON>` 执行，核心写入操作如下：

```python
d = '/var/lib/proxy-agent/tuning'
fd, p = tempfile.mkstemp(prefix='.tuning-', dir=d)
os.fchmod(fd, 0o600)
with os.fdopen(fd, 'w') as f:
    f.write(request_json + '\n')
    f.flush()
    os.fsync(f.fileno())
os.replace(p, d + '/desired.json')
fd = os.open(d, os.O_RDONLY)
os.fsync(fd)
os.close(fd)
```

所有应用、负例和 clear 均只通过该方法触发 path。没有手工启动 tuning service，没有直接以 root 执行 `proxy-agent --apply-tuning`。
