## 3. 清理与还原

- 停止并取消启用 `proxy-agent`，结束隔离面板与本地 HTTP 目标；确认没有残留的 sing-box／xray／面板进程，除 sshd 外无监听端口。
- 宿主还原：A、C 两次安装的文件分别移至 `/root/qui-v151-accept/host-aside-A/`、`host-aside-C/`，起点的二进制、`/etc/proxy-agent`、`/var/lib/proxy-agent`、`/usr/local/lib/{proxycontrol,proxy-agent}`、`/var/lib/proxycontrol-install` 移回原位，服务单元从起点备份还原并 `daemon-reload`。复核（`evidence/14-restored.txt`）：配置与两个二进制的 sha256 与起点一致，`proxy-agent` disabled／inactive，两个 helper `.path` enabled。
- 删除登记码、Owner 密码、会话与 CSRF 文件、setup token、订阅与凭据中间文件、面板 TLS 私钥、面板节点 CA 目录，以及两份 aside 里的节点身份目录与 `configuration.key`。
- 保留在 `/root/qui-v151-accept/`：`src/`、`dist/`、`bin/`、`panel/`（数据库与日志，无凭据文件）、`host-backup/`、`host-aside-A/`、`host-aside-C/`（无身份材料）与 `evidence/`（已检查不含 password、token、csrf、session 关键字）。

## 4. 限制

- 只覆盖本机 systemd 的单节点；未在 Alpine/OpenRC 上重复，也未验证 Hysteria2／TUIC 等需要证书的显式核心入站、GOST 转发，仅覆盖 sing-box 的显式 `core`。
- 规划中「存储地板尚未升级」的初始状态（基线写出与格式升级之间被停服务）只由单元测试覆盖，本轮没有人为制造；A 路径证明了基线等待与正常初始化。
- 面板与节点同机，经回环地址连接；没有从外部客户端经真实公网地址验证。
- 本轮没有测试 5.45.96.43 等真实主机。规划验收中「在 5.45.96.43 升级到 1.5.1 后发布 Hysteria2」已在发布后经网页升级完成（修订 21 成功），见[发布说明](release-notes-1.5.1.md)「验证」。
- `evidence/03-verifyA.txt` 里的 journal 摘录包含该主机历史（2026-11-06 至 11-10）的旧日志，不属于本轮；本轮范围的判断以 `11-journal-bad-count.txt` 与 `11-journal-A-B.log` 为准。
