- **A1 / check (rest)**：非 root runner 的 helper 测试目录由当前账号创建，原检查固定要求 uid 0，导致约 46 项失败。`panel-update-request.sh` 仅在 `QUI_PANEL_UPDATE_TEST_ROOT` 非空时要求安装记录目录属于 helper 的 `$EUID`；无测试根目录时仍要求 uid 0。两种模式都要求 0700，原目录符号链接拒绝、请求目录 FD 固定及同文件系统检查不变。`QUI_PANEL_UPDATE_ACCOUNT` 仍只确定面板请求／状态属主，不决定可信安装记录目录属主；root 专用竞态用例的守卫未改。`update.sh` 的登记目录／数据库路径记录／恢复快照 root 检查保留：`scripts/check.sh` 通过 `"${as_root[@]}"`（非 root CI 为 sudo）运行 `update-test.sh`，该测试本身也要求 Linux/root。
