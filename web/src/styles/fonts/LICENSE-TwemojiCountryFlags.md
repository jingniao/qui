# Twemoji Country Flags font

`TwemojiCountryFlags.woff2` is copied unmodified from the npm package
`country-flag-emoji-polyfill` 0.1.10 by TalkJS
(https://github.com/talkjs/country-flag-emoji-polyfill), `dist/TwemojiCountryFlags.woff2`.
Only the font file is used; none of the package's JavaScript is included.
